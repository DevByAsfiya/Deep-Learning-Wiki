# Paper Notes

One file per paper. Naming: `year-firstauthor-short-title.md`, for example
`2015-he-deep-residual-learning.md`.

Year first keeps the folder in chronological order, which is how a subfield
actually makes sense when you read back through it.

Copy [PAPER_NOTE_TEMPLATE.md](../../_templates/PAPER_NOTE_TEMPLATE.md) to start,
then register the note in [papers/INDEX.md](../INDEX.md).

Do not commit paper PDFs. Link to the arXiv or publisher page instead. The
`.gitignore` excludes `papers/pdfs/` so you can keep local copies without them
entering version control.
